# Purple Guessing Game

Simple PHP + vanilla JS guessing game with a purple theme.

Run locally with PHP's built-in server:

```bash
php -S localhost:8000
```

Open http://localhost:8000/index.php in your browser.

Files added:
- `index.php` — front-end app shell
- `assets/style.css` — purple theme and animations
- `assets/app.js` — JS request manager and game logic
- `guess.php` — backend endpoint returning JSON
